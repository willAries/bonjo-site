# Bonjo Support

Bonjo is an AI-powered weekly planner: tell it once who you want to be, and it drafts a realistic, energy-aware week — fixed commitments stay put, heavy days get recovery slots.

Note: the app interface is currently in Simplified Chinese. English is coming.

## Quick answers

**AI features don't respond.**
AI runs on our server. Make sure you are online; each device has a daily fair-use quota. If you prefer, clear the server config in "我" → AI 设置 and the app keeps working fully offline in Demo Mode.

**Where is my data?**
Everything (profile, plans, collected items, check-ins) is stored locally on your device. No account, no login, no tracking. See the [privacy policy](./privacy).

**How do I collect things while browsing?**
Install the official "收藏到好周" shortcut from the app (收藏夹 → top-right button), then use the share sheet, Control Center, or the Action Button from any app. Details are in the in-app guide.

**How does distraction interception work?**
"我" → 分心拦截 has a one-tap install for the official "APP拦截" shortcut plus a three-step automation setup. After a timer ends, the app returns you to where you were.
