# Bonjo Support

Bonjo is an AI-powered weekly planner: tell it once who you want to be, and it drafts a realistic, energy-aware week — fixed commitments stay put, heavy days get recovery slots.

Note: the app interface is currently in Simplified Chinese. English is coming.

## Quick answers

**AI features don't respond.**
AI features run on our server. Make sure you are online; each device has a daily fair-use quota. If AI is temporarily unavailable, everything else in the app keeps working locally and you can retry later.

**Where is my data?**
Your profile, plans, collected items, check-ins and journals are stored locally on your device — no account, no login, no tracking. When you use AI features (weekly planning, collection summaries), the content needed for that feature is sent to our server to be processed, and is used only to produce the result you asked for. See the [privacy policy](./privacy) for the full picture.

**How do I collect things while browsing?**
Install the official "收藏到好周" shortcut from the app (收藏夹 → top-right button), then use the share sheet, Control Center, or the Action Button from any app. Details are in the in-app guide.

**How does distraction interception work?**
"我" → 分心拦截 has a one-tap install for the official "拦一下 Blocky" shortcut plus a three-step automation setup. After a timer ends, the app returns you to where you were.
